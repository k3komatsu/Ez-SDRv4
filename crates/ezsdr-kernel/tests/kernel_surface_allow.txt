# OV-23 / OV-23b — the Kernel-does-not-grow allow-list.
#
# One line per module-level public item: `name = justification`. The justification
# is either a **specific token** from audit §13's Kernel tree, or `NEW: <one line>`
# for a type the Kernel has that audit §13 does not name.
#
# The `NEW:` count, not the raw public-item count, is the "Core remains small"
# measurement (OV-23b). Audit §13's `data` line ends with the catch-all "Stream
# Contract (normative)", which would otherwise absorb every type spec 02 invents;
# each of those is written out here instead.

FEATURE:testing = NEW: OV-20 ships ManualTimeAuthority in src/ behind the non-default `testing` feature; every item it gates is excluded by this one line.
