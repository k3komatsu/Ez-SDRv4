01 / OVERVIEW

できること

Ez-SDR v4 でできること

Pythonから仮想無線機を操作し、送受信や測定を行えます。実験条件、実行中の操作、受信データを記録し、同じPC環境で同じ条件を再実行したり、条件を変えた結果を比べたりできます。SDR実機との接続は計画中です。

実験条件と実行環境を分ける

実験条件（ExperimentSpec）には、周波数やサンプルレート、必要な入出力を記述します。実行環境（BindingProfile）には、使用する仮想無線機や周囲の条件を記述します。同じ実験条件を、異なる環境で試せる設計です。

実験条件機器・環境実行前に確認

02 / WORKFLOW

実験の流れ

条件を確かめてから実験し、記録する

Pythonから実験条件を指定すると、実行前に仮想無線機がその条件に対応できるかを確認します。実験中の操作や受信データを保存し、あとから結果を確かめられます。

現在のPython APIで実験する手順実行前に条件確認 · 実験後に記録を確認
01 · 条件実験条件を書く

周波数、サンプルレート、入出力などを指定

02 · 機器機器と環境を選ぶ

使う仮想無線機や実験環境を設定

03 · 確認実行前に確認

機器が条件を満たすか、動かせるかを確認

04 · 実行仮想実験を実行

現在はPC上の仮想無線機で動作

05 · 記録条件と結果を保存

設定、出力データ、実行中の出来事を記録

仮想実験では、実時間を待たずに実験時間を進められます。同じPC環境で同じ条件を使って再実行し、結果を比べられます。

実装済み · PYTHON API

Pythonから送受信を試す

Pythonで生成した信号を仮想無線機から送り、戻ってきた信号を受信する例です。Python APIは実装済みです。利用にはPython 3.9以降とNumPyが必要です。実験実行プログラム（ezsdr-server）はリポジトリからビルドして利用します。

動作する最小例を見る ↗ 
import numpy as np
import ezsdr

x = np.exp(2j * np.pi * np.arange(1000) / 100).astype(np.complex64) * 0.5

with ezsdr.connect() as sdr:
    sdr.tx.repeat(x)
    y = sdr.rx.capture(100_000)

print(f"captured {len(y)} samples")
print(f"記録ファイル: {sdr.manifest_path}")
03 / DESIGN

設計の考え方

実験を支える三つの役割

実験の進行管理、周波数などの設定項目、無線機や保存処理を行う機能部品を分けています。Python APIは実装済みで、AIからも同じ実験条件を扱えるようにすることは今後の計画です。

実験の進行管理（Kernel）

条件を確認し、実験の開始・停止から、設定や結果の記録までを管理します。

条件確認実行管理結果記録

分野ごとの設定項目（Vocabulary）

周波数やサンプルレートなど、無線機やシミュレーションで使う項目の名前と意味を定めます。

無線機シミュレーションデータ保存

交換できる機能部品（Modules）

仮想無線機、信号処理、データ保存などを、共通の接続ルールに沿って追加できます。

仮想無線機信号処理ファイル保存

AI-Nativeは設計方針であり、AI連携機能はまだ実装されていません。将来AIが実験条件を作成・確認するときも、サンプルごとに時間を守る信号処理は専用プログラムが行います。
