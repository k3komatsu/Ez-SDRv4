# `04-run-and-session.md` — RS-n disposition table

57 rules. Row format per [README.md](README.md). Tests are in `crates/ezsdr-kernel/tests/run_session.rs`
unless the Carrier column names a different file. HEAD `e57d6db`, `cargo test -p ezsdr-kernel --test
run_session --test spec_binding --test event_hotpath` clean (66/66 in `run_session.rs`, 87/87 in
`spec_binding.rs`, 1/1 in `event_hotpath.rs`).

This document has no Phase 1 coordinator, dispatch loop or `Session` runtime object in `src/`: `RS-4` and
`RS-18` carry explicit forward markers in their own text, and several other rules describe a composition
(a "Run", a Run-to-Manifest pipeline) that nothing in `src/` assembles yet, recorded below as `GAP`.
