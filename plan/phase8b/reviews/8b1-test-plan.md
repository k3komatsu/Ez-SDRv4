## 0. Decisions and the deadline seam

### 0.1 The seam: where it lives, what production uses, how a test drives it

It lives in `crates/ezsdr-radio-uhd/src/provider/mod.rs`, on `UhdRadio`, beside the existing test-only field `fail_next_rx_spawn` and in the same style as `Core::probe` ("nothing outside the test build"). Two items:

1. `fn join_now(&self) -> Instant`. In production it is `Instant::now()` (real time) and nothing else. In the test build it first asks `#[cfg(test)] join_seam: JoinSeam`, a struct of two `Option<Arc<dyn Fn…+Send+Sync>>` fields, `now: Option<Arc<dyn Fn() -> Instant …>>` and `at: Option<Arc<dyn Fn(&JoinPoint<'_>) …>>`, and returns the seam's instant when one is set. `join_now` is the **only** reader of the stage's deadline: `let until = self.join_now() + JOIN_BOUND;` and the expiry test `self.join_now() >= until`. The poll's 1 ms wait stays real time and stays `host.wait(None, Some(Instant::now() + Wall::from_millis(1)), seen);` token for token (rows N51A-13 and N51A-14 keep matching once). With the seam unset (every existing test, and every production run) the stage behaves exactly as today's `join` does.
2. `fn join_point(&self, point: JoinPoint<'_>)`: calls the `at` hook if set; an empty function outside the test build (`let _ = point;`), as `Core::probe` does. The points, in `stop`'s and the stage's code order:
   - `Enqueued { dir }`: in `stop`, after every `Shutdown` of direction `dir` has been sent (`Tx` then `Rx`), before that direction's stage is entered. No point for control (it has no command).
   - `Begun { stage, until, finished }`: in the stage, after the names present were taken out of `running.threads` and the deadline was read, before the first check. Not called for a stage with no thread present (it returns before reading the clock, calling a point or waiting).
   - `Polled { stage, round, finished }`: in the stage, each time the check found some thread unfinished and the deadline not reached, before the 1 ms wait; `round` counts from 0. A stage whose threads are all finished at its first check makes no `Polled`.
   - `Noted { stage, name, finished }`: in the stage, after the note for `name` (unfinished at the sweep) was written and the name inserted in `detached`.
   `stage` is `Stage::{Control, Tx, Rx}`; `finished: &dyn Fn(&str) -> bool` reads `is_finished()` of the named handle the stage still holds (true for one already joined), so a hook can wait until a released worker's handle has really finished.

Driving it (test helpers next to `running_radio`, `#[cfg(test)]`):
- `JoinClock { base: Instant, offset_ns: AtomicU64, reads: AtomicUsize }` with `now()` (`base + offset`, counts a read), `advance(Duration)` and `elapsed()` (the offset). `radio.join_seam.now = Some(Arc::new(move || clock.now()))`.
- A hook closure installed in `radio.join_seam.at` runs on the joiner's thread (the thread that calls `stop`). It may advance the clock, send on a channel, block on a channel, spin on `finished(name)`, read `core.rec`, and drain the test-owned command receivers. A helper `advance_while(stages, step)` makes the hook add `step` (250 ms) to the clock at every `Polled` whose stage is in `stages`: **virtual time passes only as the joiner polls, and only in stages whose threads are all deliberately stuck or held**. A stage that is expected to end by itself is left with a frozen clock, so it can never expire, and no wall time decides it.
- Virtual elapsed time is exact: a stage over stuck threads polls rounds 0..3 (each adds 250 ms), then the check finds `now == until` and breaks, so a stuck stage consumes exactly `JOIN_BOUND` of virtual time (4 `Polled`), whatever the real speed of the machine.
- Workers are test-spawned threads (`radio.spawn(&core, name, body)`: host-registered, `catch_unwind` as in production). `Stuck`: waits on its release channel only (the test drops the sender at the end, so no thread outlives the test). `Held`: the same, released by the hook or the test. The test owns the `Receiver<TxCmd>` / `Receiver<RxCmd>` of `Running.to_tx` / `to_rx`; no worker reads a command except where a test says so, so the queues can be inspected with `try_recv` at a point. Panicking worker: `panics_when_released` (existing).

### 0.2 What the points are for (Major 1 and 2)

The clock seam makes the budget verdict a function of the number of polls, not of the machine. The points replace "did it happen within a real second" by "was it in this state when this stage began or ended". Receipt by a worker is never asserted: enqueue is read from the queue the test owns, at the stage boundary.

### 0.3 The completion sweep (Major 3), specified

The stage: take the names that are present in `running.threads` out of it, in the given order; if none, return. Take `until = self.join_now() + JOIN_BOUND`; call `Begun`. Loop: `seen = host.generation()` first; if every handle `is_finished()` or `self.join_now() >= until`, leave the loop; otherwise call `Polled`, then `host.wait(None, Some(Instant::now() + Wall::from_millis(1)), seen)`. After the loop run **one completion sweep**: read `is_finished()` of every handle once, into a vector, before any thread is joined and before any note is written. That vector is the stage's decision. Then, in name order: a handle the sweep found finished is joined (`let _ = handle.join();`, as today); one it found unfinished gets the note `did not join within 1 s; left detached`, goes into `detached`, and `Noted` is called. A thread that ends after the sweep is detached. The sweep is the instant UR-16 speaks of: "a thread that has not ended when its stage's bound ends".

### 0.4 Other decisions

- Each stage's deadline is read when that stage begins (after the stage's `Shutdown` sends). Names not present (a `start` that failed before spawning them) are skipped; a stage with none present does nothing, reads no clock, calls no point.
- `join` (one name) is removed. Its two direct callers (`ur_16_join_waits_idle_…`, `ur_16_the_join_bound_cuts_in_real_time_…`) call `join_stage(&core, &["uhd-control".to_owned()])` with the seam unset. Planned shape for the rows: `fn join_stage(&mut self, core: &Core, stage: Stage, names: &[String])`, called `Stage::Control` with `["uhd-control"]`, `Stage::Tx` with the `tx_name(k)` list, `Stage::Rx` with the `rx_name(k)` list (the implementer may rename; the rows follow).
- The test-only spawn failure: `fail_next_rx_spawn: bool` becomes `fail_rx_spawn_of: Option<usize>` (the stream index whose uhd-rx spawn fails); the existing `ur_15_a_failed_rx_owner_spawn_abandons_its_started_chain_before_cleanup` sets `Some(0)` (its behaviour unchanged), S9 sets `Some(1)`.
