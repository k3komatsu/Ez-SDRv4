## 0. The shape, as built

- **Kernel** (`crates/ezsdr-kernel`): `session::InitialRequests = BTreeMap<Ident, BTreeMap<Key, Scalar>>`; `implicit_spec(profile, registry, providers, sinks, initial)` puts a resource's requests into its `requires` as `Eq`, declares each key's Vocabulary once at its registered major (`ModuleRegistry::vocabulary_of`), refuses a name that is no Provider resource (`RS-12: initial requests name <x>, which is no Provider resource`); `coordinator::connect(profile, initial, assembly, lease)` is the one entry, every caller edited (no second entry). The public-surface count is 113 of 292 (`kernel_surface_allow.txt`, `ov_23b`).
- **Wire** (`crates/ezsdr-server/src/protocol.rs`, schemas regenerated, `ea_06_schema_freeze` green): `connect { profile?, lease?, initial? }`, `initial: { "<resource>": { "rx": [StreamInit], "tx": [StreamInit] } }`, `StreamInit { number | name, channels: [integer | string], sample_rate?, frequency?, gain?, antenna? }` (the value objects keyed by a channel of the stream); `connected { …, streams: { "<resource>": { "rx": {name: n}, "tx": {…} } } }`. A direction absent or `[]` is every channel in no stream; the channels are `oneOf integer | string` already, so channel names (stage 1b) add no schema change, and in stage 1 a string channel or value key is refused ("channel names need stage 1b").
- **Server** (`crates/ezsdr-server/src/initial.rs`): after `assemble`, before `coordinator::connect`, it counts each direction's channels from the Provider's tree, numbers names (smallest number the direction does not claim, in request order), refuses what the layout cannot meet, and builds `InitialRequests`. It writes no `-1` for an unlisted channel: RM-30's default already is "in no stream", so the Spec carries only what was asked (this closes the two rows Sol said could not be killed, P1328/P1329 of rev 2: dropped, the explicit none-requirements are not contractual).
- **Radio** (`crates/ezsdr-radio/src/channels.rs`): `default_stream` is deleted; every `stream` default is -1 (both directions, `coerce`'s `Present` too).
- **Python** (`python/ezsdr/session.py`): `ezsdr.Stream(channels, sample_rate, frequency, gain, antenna)`; `connect(profile=None, *, server, runs_dir, lease, radio=None, rx=None, tx=None)`; the dict keys are a stream number (`int`) or name (`str`); `rx_streams["main"]` resolves a name through `connected.streams`; the `rx` alias raises `Error` when receive stream 0 holds no channel (ruling Q2); `sdr.tx.repeat` on a stream with no channel is refused by the existing channel-count check.
