## Appendix A: the probe (outside the repository)

Transcription of `tx_handed_end` (`lib.rs:1393-1412`) and of `tx.rs:647-671`, compared over `we` = 10 000, start in `[we - 80, we + 5]`, len in {repeat, 1…70}, started in {false, true} (12 212 cells):

| Variant | Differences from today's formula |
|---|---|
| Fresh device burst for every booking, no cap | 1 705, all started (an open booking with fewer than 32 samples of window left would need 32) |
| Started = continuation, cap = infinity | 2 495, all started (a continuation needs all of `wanted`; with no cap it never fits) |
| Started = continuation, cap = what fits | 0 |
| **Window-only mode**: first send needs `min(len, 32)`, a continuation takes what fits | **0** |
| W = 0 (`we` = the Stop sample) | every value <= `we`, so with the Stop sample as the lower bound the cut is the Stop sample, as `o1_mock_t9f_…` pins |

So "the same function without a send-size cap" is the window-only mode: a continuation takes `min(remaining, avail)`, a device-burst first send still needs `min(wanted, 32)`. The not-started cells agree under every variant.
