# Phase 8 1b-7a — test plan

This plan covers 1b-7a’s held-`TxBurst` cancellation report rule; RX overflow/D2 and the later phases are out of scope.

## Contract under test

The Vocabulary owns the decision, represented by one cancellation-reason enum with `Stop`, `ProviderStop`, `Loss`, and `ColdChange`, plus one predicate that answers whether cancellation emits `radio.COMMAND_REJECTED`:

| Reason | `COMMAND_REJECTED` | Per-burst `rejected` record |
|---|---:|---:|
| `Stop` (stream or device) | 0 | 1 |
| `ProviderStop` | 0 | 1 |
| `Loss` | 0 | 1 |
| `ColdChange` | 1 per cancelled burst | 1 per burst |

Keep the existing provider-specific record/event reasons. Do not share reason strings, add a trait, or change Kernel types. The enum covers only held bursts cancelled by these external events, not receipt refusals, late-policy drops, underflow recovery, or pending updates.

## Harness and observations

Use `crates/ezsdr-acceptance/tests/parity.rs`’s `MockRig` and `UhdRig` (`:189-415`) to run the same TX actions against MockRadio and `UhdRadio`/`FakeDevice`. Their current `PrepareContext.inputs` are empty (`:229`, `:339`), so add the smallest constructor support needed to supply one valid shared waveform artifact and bytes to both rigs; give MockRig the `sim.faults` environment for loss. Configure FakeDevice’s existing `Lost` fault at the corresponding device-clock instant. To prove UHD has booked ordered actions without a sleep oracle, enqueue a distinct, deliberately refused barrier Action after the burst and cancellation and wait for its reason-specific `COMMAND_REJECTED`; Mock barriers are asserted as positive event observations too. ActionReceiver/uhd-control processes these in order. For a cancellation completed by uhd-tx, finish/join the Provider before inspecting its recorded rows. Wall-clock timeouts are watchdogs only, not assertions.

Observe all of the following; do not use event counts alone:

- `COMMAND_REJECTED` count and provider-specific reason, using parity’s `rejected_reasons` helper (`:737-740`).
- Each provider’s `ezsdr.radio.*.rejected` rows: count, `kind == "tx_burst"`, and its existing reason.
- MockRadio’s `bursts` section and TX stats; UHD’s `FakeDevice` `tx_send` calls and recorded bursts. A cancelled future waveform must not appear in either transmission record.
- For a Stop on a clock that remains active, submit another burst later on the same clock and verify it transmits. Focused owner tests inspect that the cancelled burst's exact shared reservation was released.

Use future, distinct burst start times and wait until each queued Action has been consumed/booked before applying the cancellation. A row created for that burst is also required, so an empty action/result comparison cannot pass. Compare report counts across Providers, but do not compare reason strings byte-for-byte.
