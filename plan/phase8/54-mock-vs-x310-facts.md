Conventions. `M:` = MockRadio side, `H:` = X310 + UHD Module side. Paths are relative to the repository root. Spec cites are `file:line` of the rule's first line (`07` = `design/07-radio-model.md`, `09` = `design/09-mock-radio.md`, `11` = `design/11-simulation-channel.md`, `18` = `design/18-uhd-radio.md`, `08` = `design/08-simulation.md`).
