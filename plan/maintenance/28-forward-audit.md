## Findings (verified)

- **A1** Two multi-device models in the record; only one root per instance aligns to the sample (KC-15). Decision 1.
- **A2 / C1** TM-18's first and last sentences promise relations the Kernel has no path for. Decision 1.
- **A3 / C3** `Manifest::write_section` silently replaces a section of the same name written by another instance of the same Module; Modules embed `<id>` in section names to avoid it (MR-27, UHD), and MR-2 / UR-5 narrow `id` for that reason. `crates/ezsdr-kernel/src/manifest.rs:403-421`, `coordinator/ending.rs:98-126, 256-263`.
- **B2** A Provider's ports declare no memory domain, and MA-39's check skips links touching a resource endpoint (`plan/islands.rs:225-227`); Executors, Sinks and Links declare theirs. D81: "The field cannot be added after the freeze."
- **B3** design/02:7 says `pdu.*` and `tensor.*` register later unchanged, but SC-12, SC-13, SC-23…SC-32 are sample-stream rules; SC-4's `ezsdr.event.<schema-id>` is registered nowhere in code.
- **C4** `PrepareContext` and `Assembly` are pub-field structs without `#[non_exhaustive]`, built by struct literal in Module tests and the server; a later field is a major change. Verifier note (INFERRED): a link-fed transmit component cannot find its transmit SampleClock, since `AttachedPort` has no bound node (`module_api.rs:990-997`).
- **C5** No spec 01–06 rule says a Sink fragment's content is its `OutputReq` (`plan/compile.rs:142`), on which the capture Sink and HD-9 depend.

Refuted, no freeze cost: B1 (Fidelity has no "not applicable": `real` is the identity of the per-aspect min; optionally one sentence in MA-42), B4 (MA-22's cycle check: the port can sit on a stream sub-node), B5 (calibration validity: a Vocabulary AdmissionCheck covers it), C2 (ending-refusal check names: optionally one Kernel const).

## Before the freeze review

Answers in a fixed JSON shape, every flag with path:line; flags without evidence are dropped. Claude verifies the flagged rows and spot-checks a sample of the clean ones to estimate the miss rate.
