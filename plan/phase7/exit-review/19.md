# `19` — the amendments disposition table

Every rule spec 19 ([`19-amendments.md`](../19-amendments.md)) adds or amends, in its order: `KG-1…KG-14` and the rules each amends or adds, then `VE-1…VE-6` likewise, then the governance rules `GZ-1…GZ-10` of [`00-overview.md`](../00-overview.md) §6 with the Phase 2 rules two of them amend. The amended text is in `design/` (GZ-7). `read from` gives each test source and function so the assertion can be inspected directly. The Kernel's device-paced tests are in `crates/ezsdr-kernel/tests/device_paced.rs` with the §0 doubles `WallAuthority` and `ThreadedProvider` (`tests/support/run_doubles.rs`); spec 19's tables say `coordinator.rs` for them. The UHD Module's tests are in `crates/ezsdr-radio-uhd/tests/fake.rs` (see [18.md](18.md)); the server's in `crates/ezsdr-server/tests/protocol.rs`; the Python tests are cited as `test_easy_api.py::<name>` (`python/tests/test_easy_api.py`, run under GY-7). Mutation ids are rows of `plan/phase7/tools/mutations.json` (Appendix A, GZ-6), each killed by the test named with it. A clause that no test body asserts is written out in its row as **Not asserted** and listed in the [README](README.md).
